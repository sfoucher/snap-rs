# snap-rs Viewer (Plan 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cross-platform desktop viewer that opens GeoTIFF/COG (and any GDAL raster) and offers SNAP's image-view features: stretch, RGB composites, pixel info, masks, band maths, subset export.

**Architecture:** A `Product → Band → RasterSource` model where every band exposes `read_tile(level, tx, ty)`. A global `TileCache` fronts all sources and feeds a wgpu canvas that applies stretch/palette on the GPU. GDAL lives only in `snap-io-gdal`; the GUI lives only in `snap-gui`.

**Tech Stack:** Rust 2021, `ndarray`, `gdal`, `proj`, `chumsky`, `rayon`, `lru`, `thiserror`, `eframe`/`egui`/`egui_dock`/`wgpu`, `rfd`, `serde`/`serde_json`.

**Spec:** `docs/superpowers/specs/2026-10-20-snap-rs-design.md` (sections 4.1–4.7, 4.9, 5, 6, 7). GPF and CLI (4.8, 4.10) are Plan 2.

## Global Constraints

- Tile size is 512 × 512 (`TILE: u32 = 512`); edge tiles are clipped, never padded. Level 0 is full resolution; level n is downsampled by 2ⁿ.
- Dependency direction: `snap-gui → snap-io-gdal → snap-io → snap-core`; `snap-expr → snap-core`. `snap-core`, `snap-expr`, `snap-io` must not depend on `gdal` or `egui`.
- One `thiserror` error enum per crate: `IoError` (snap-io), `ExprError` (snap-expr), `GeoError` and `CoreError` (snap-core). GDAL errors are captured via GDAL's error handler, never printed to stderr.
- `DataType` variants: `U8, I8, U16, I16, U32, I32, F32, F64`.
- Default stretch is percentile 2–98 %.
- Pyramid sidecars live under the OS cache dir (`dirs::cache_dir()/snap-rs/pyramids/<key>/`), key = hex SHA-256 of `(canonical path, mtime, size)`.
- CI matrix: ubuntu-latest, macos-latest, windows-latest; GDAL from system packages or vcpkg.
- Prose and UI copy in English; comments only where the code can't show the why.

## Review Focus

1. A GeoTIFF with no geotransform (pixel-is-point, unreferenced scan) must open with `NoGeoCoding` and Pixel Info shows "—" for lat/lon, not a crash. → Task 12 test `geotiff_without_georef_uses_nogeocoding`.
2. A band whose values are all `no_data` (or constant) must not divide by zero in stretch; histogram has one bin, min == max, slider still works. → Task 7 test `stats_of_constant_band`.
3. A band-maths expression referencing a band that doesn't exist must fail at parse/bind time with the span of the identifier, never panic in `read_tile`. → Task 9 test `unknown_band_is_bind_error`.
4. A 40 000 × 40 000 COG must open without reading more than the tiles on screen; opening must not compute stats on level 0. → Task 7 test `stats_sample_from_coarsest_level`, Task 11 test `open_reads_no_tiles`.
5. Right/bottom edge tiles of a raster not divisible by 512 must be clipped in both the source and the GPU upload, not stretched. → Task 2 test `tile_rect_clips_edges`, Task 15 test `visible_tiles_includes_clipped_edge`.

- Produces:
  ```rust
  pub struct Pyramid { /* inner: Arc<dyn RasterSource>, levels: u8, cache_dir: Option<PathBuf> */ }
  impl Pyramid {
      pub fn needed_levels(w: u32, h: u32) -> u8;   // smallest n such that level_size fits in one TILE, min 1
  ```

### Task 8: Expression parser

**Files:**
- Create: `crates/snap-expr/src/{error.rs,ast.rs,parser.rs}`, `lib.rs`

**Interfaces:**
- Produces:
  ```rust
  #[derive(Copy, Clone, Debug, PartialEq)] pub struct Span { pub start: usize, pub end: usize }
  pub enum BinOp { Add, Sub, Mul, Div, Rem, Pow, Lt, Le, Gt, Ge, Eq, Ne, And, Or }
  pub enum UnOp { Neg, Not }
  pub enum Func { Sqrt, Exp, Log, Log10, Abs, Min, Max, Pow, Sin, Cos, Tan, Nan, Inf, Floor, Ceil, Round }
  pub enum Expr { Num(f64, Span), Const(&'static str, Span) /* PI, E, NaN */, Ident(String, Span),
                  Unary(UnOp, Box<Expr>, Span), Binary(BinOp, Box<Expr>, Box<Expr>, Span),
                  Ternary(Box<Expr>, Box<Expr>, Box<Expr>, Span), Call(Func, Vec<Expr>, Span) }
  impl Expr { pub fn span(&self) -> Span; pub fn identifiers(&self) -> Vec<(String, Span)> }
  pub fn parse(src: &str) -> Result<Expr, ExprError>;
  #[derive(thiserror::Error)] pub enum ExprError { Parse{ msg: String, span: Span }, UnknownFunction{ name: String, span: Span },
                                                   Arity{ name: String, expected: usize, span: Span }, UnknownBand{ name: String, span: Span },
                                                   TypeMismatch{ msg: String, span: Span } }
  ```
